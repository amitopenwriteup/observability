# 🚀 AIOps & Dynatrace Labs

This repository contains **workshops, labs, and learning materials** for exploring **Dynatrace, AIOps concepts, observability, and integrations**. It is designed for hands-on practice in **monitoring, automation, and AI-driven operations**.

## 🧩 Key Topics

* **AIOps Concepts** – What is AIOps, why it matters
* **Dynatrace OneAgent** – Deployment & monitoring setup
* **DQL (Dynatrace Query Language)** – Querying logs & metrics
* **Grail Database** – Data lakehouse for observability
* **OpenPipeline** – Data pipelines in Dynatrace
* **PurePath** – End-to-end distributed tracing
* **Service-Level Objectives (SLOs)** – Defining & monitoring SLAs
* **Dynatrace API** – Automation & integrations
* **Monitoring Integrations** – AWS, Kubernetes, Jenkins, DBs
* **RBAC** – Role-based access control in Dynatrace

## ⚙️ Requirements

* A Dynatrace account (SaaS or Managed)
* Kubernetes cluster (for monitoring labs)
* Jenkins / AWS environment (for integration labs)
* Office / PDF reader for lab materials

## 🚀 Getting Started

1. Open the relevant **Lab document** (`.docx` or `.pdf`)
2. Follow the **step-by-step instructions**
3. Explore **Dynatrace dashboards, queries, and pipelines**
4. Extend with your own observability use cases

## 🎯 Learning Outcomes

By completing these labs, you will be able to:

* Deploy and configure Dynatrace agents
* Build monitoring pipelines with DPL & OpenPipeline
* Query metrics, logs, and traces using DQL
* Create and monitor SLOs for applications
* Understand **PurePath** distributed tracing
* Automate monitoring with APIs and CI/CD integrations
