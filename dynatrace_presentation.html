Davis AI: Intelligent Automation

🧠 What is Davis?

Davis is Dynatrace's AI causation engine that analyzes billions of dependencies in real-time to automatically detect anomalies, identify root causes, and predict future issues.

🔍 Anomaly Detection

Dynamic Baselines: Learns normal behavior automatically

Context-Aware: Considers time, day, seasonality

Zero Config: No threshold tuning required

🎯 Root Cause Analysis

Dependency Mapping: Traces issues across entire stack

Impact Assessment: Identifies affected users/services

Single Alert: One problem, not hundreds

📈 Predictive Analytics

Capacity Forecasting: Predicts resource exhaustion

Trend Analysis: Identifies degradation patterns

Proactive Alerts: Warns before issues occur

💡 Smart Suggestions

Remediation Advice: Actionable recommendations

Configuration Insights: Optimization suggestions

Best Practices: Security and performance tips

Davis Problem Detection Flow

  • Detection: Identifies anomalies across all monitored entities
  • Correlation: Groups related events into single problems
  • Root Cause: Analyzes dependencies to find the origin
  • Impact: Determines affected services and users
  • Notification: Sends context-rich alerts to relevant teams
Advantage: Davis reduces alert noise by 90%+ compared to traditional threshold-based monitoring.

Service Level Objectives (SLOs)

Reliability Engineering

Define, track, and alert on SLOs to ensure your services meet reliability targets and error budgets.

🎯 SLO Definition

Availability: % of successful requests

Performance: Response time percentiles

Custom: Business-specific metrics

💰 Error Budgets

Calculation: Automatic budget tracking

Burn Rate: How fast budget is consumed

Alerts: Warn when budget is exhausted

📊 Multi-Window Analysis

Time Windows: Daily, weekly, monthly tracking

Trend Analysis: Historical performance

Forecasting: Predict SLO violations

🔔 Smart Alerting

Burn Rate Alerts: Fast/slow burn detection

Warning Thresholds: Proactive notifications

Multi-Window: Prevent false alarms

SLO Best Practices

  • Start with availability SLOs (99%, 99.9%, 99.95%)
  • Add latency SLOs based on user experience requirements
  • Use error budgets to balance features vs. reliability
  • Create dashboards showing SLO status for all critical services
  • Review and adjust SLOs quarterly based on business needs
Integration: SLOs work seamlessly with Davis AI - problems automatically include SLO impact analysis.
