How Auto-Discovery Works

Discovery Process Flow

1

OneAgent Installation

OneAgent is installed on the host operating system with a single command. It immediately starts monitoring the host-level metrics.

2

Process Detection

OneAgent scans for all running processes on the host. It identifies process types (Java, .NET, Node.js, Apache, NGINX, databases, etc.) and begins monitoring them.

3

Automatic Instrumentation

For supported technologies, OneAgent automatically instruments the application code by injecting monitoring hooks at runtime—no restart or code changes needed.

4

Service Discovery

OneAgent detects services by analyzing application communication patterns. It identifies service entry points (REST endpoints, message queues, databases) and creates service entities.

5

Dependency Mapping

As requests flow through the system, OneAgent traces every call and builds a real-time dependency map showing how services, processes, and infrastructure components interact.

6

Continuous Monitoring

OneAgent continuously monitors for changes: new processes starting, services being deployed, configuration changes, and updates the topology automatically.

⏱️ Discovery Timing

Host Detection: Immediate (< 1 minute)

Process Detection: 1-3 minutes after process starts

Service Discovery: 5-10 minutes (requires traffic)

Full Topology: 15-30 minutes with active traffic

Service Discovery & Mapping

Automatic Service Detection

OneAgent automatically identifies services by analyzing entry points and communication patterns. No service definitions or configuration files required.

🎯 How Services Are Discovered

  • Entry Point Detection: Identifies HTTP endpoints, REST APIs, SOAP services, message queue listeners
  • Traffic Analysis: Observes actual requests to determine service boundaries
  • Technology Recognition: Detects service frameworks (Spring Boot, Express.js, ASP.NET Core)
  • Naming Intelligence: Auto-generates meaningful service names based on technology patterns
  • Grouping: Combines related endpoints into logical services

Application & User Experience Discovery

Frontend Application Monitoring

OneAgent can automatically inject Real User Monitoring (RUM) into web applications, or you can manually add the JavaScript snippet for full user experience visibility.

🖥️ Web Application Discovery

  • Auto-Injection: For supported web servers (Apache, NGINX, IIS), OneAgent can automatically inject RUM JavaScript
  • Framework Detection: Identifies React, Angular, Vue.js, jQuery applications
  • SPA Support: Full support for single-page applications with route change tracking
  • User Actions: Automatically captures clicks, form submissions, AJAX calls
  • Performance: Core Web Vitals, page load times, resource timing
