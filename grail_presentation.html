Grail DB

Dynatrace Data Lakehouse Architecture

A revolutionary approach to observability data storage

What is Grail?

Data Lakehouse - Combines data warehouse performance with data lake flexibility
Unified Storage - Single solution for all observability data types
Hyperscale - Designed to handle massive volumes of telemetry data
Real-time Analytics - Query data at massive scale with subsecond performance

Supported Data Types

Grail provides unified storage for:

📊 Metrics
📝 Logs
🔍 Traces
⚡ Events
👤 User Sessions
🌐 Synthetic Tests
🔒 Security Events
💼 Business Events
All data types stored in a single, queryable format with full context preservation

Storage Layer

• Analytics

Key Architectural Features

📦 Columnar Storage - Optimized for analytical queries and compression
🔄 Schema-on-Read - Flexible data modeling without predefined schemas
⚡ Hot/Warm/Cold Tiers - Intelligent data tiering for cost optimization
🔗 Context Preservation - Maintains relationships between all data types
🚀 Distributed Processing - Parallel query execution across nodes

Dynatrace Query Language (DQL)

Purpose-built query language for Grail:

Intuitive Syntax - Pipeline-based query structure similar to modern data processing
High Performance - Optimized for time-series and observability data
Unified Queries - Query across logs, metrics, traces in a single statement
Real-time Results - Subsecond query response even on petabytes of data
