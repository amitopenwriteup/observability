LAB 1

Setting Up Your Dynatrace SaaS Free Trial

Step-by-Step Hands-On Lab

🎯 Lab Objectives

Duration: 15-20 minutes

Difficulty: Beginner

What You'll Learn:

  • How to sign up for a Dynatrace SaaS free trial
  • Understanding the Dynatrace environment structure
  • Navigating the Dynatrace UI
  • Generating and managing access tokens
  • Exploring the deployment options

Prerequisites

  • Valid email address (business email recommended)
  • Web browser (Chrome, Firefox, Edge, or Safari)
  • Internet connectivity
  • No credit card required for trial

📊 Trial Limits

Duration: 15 days full-featured trial

Hosts: Monitor up to 8 hosts

Features: Full access to all Dynatrace capabilities

Data Retention: 35 days

Support: Community support and documentation

⚠️ Important: Use a business email address when possible. Free email providers (Gmail, Yahoo, etc.) may have limited trial features or require additional verification.

Step 1: Sign Up for Free Trial

1 Navigate to Dynatrace Website
  • Open your web browser
  • Go to https://www.dynatrace.com/trial
  • You should see the "Start your free trial" page
📸 Screenshot: Dynatrace trial landing page with "Start free trial" button
2 Fill Registration Form
  • Click on "Start free trial" button
  • Enter your Business Email address
  • Enter your Full Name
  • Enter your Company Name
  • Select your Country/Region
  • Create a strong Password
    • Minimum 8 characters
    • Must include uppercase, lowercase, and numbers
    • Special characters recommended
  • Check the box to agree to terms and conditions
  • Click "Start trial"
💡 Tip: Choose a region close to your location for better performance:
  • US: For North America
  • EU: For Europe
  • APAC: For Asia-Pacific (Sydney, Singapore)
  • AUS: For Australia
3 Email Verification
  • Check your email inbox for verification email from Dynatrace
  • Open the email with subject: "Verify your Dynatrace account"
  • Click on the "Verify email" button or link
  • You'll be redirected to the Dynatrace login page
⚠️ Note: If you don't receive the email within 5 minutes:
  • Check your spam/junk folder
  • Add noreply@dynatrace.com to your contacts
  • Use the "Resend verification email" option

Step 2: First Login & Environment Setup

4 Initial Login
  • After email verification, you'll be at the login page
  • Enter your email address
  • Enter your password
  • Click "Sign in"
📸 Screenshot: Dynatrace login page
5 Environment Creation
  • Dynatrace automatically creates your first environment
  • Environment naming convention: [your-name]-trial or custom name
  • You'll see "Creating your environment" progress indicator
  • Wait 30-60 seconds for provisioning to complete

🏗️ What is an Environment?

An environment is an isolated monitoring workspace with:

  • Its own URL (e.g., abc12345.live.dynatrace.com)
  • Separate data storage and retention
  • Independent user access and permissions
  • Unique configuration and settings
  • Own set of access tokens
6 Welcome Screen
  • You'll land on the Dynatrace welcome screen
  • You may see a guided tour popup - you can take it or skip it
  • Note your environment ID in the URL bar
  • Familiarize yourself with the main navigation menu on the left
💡 Pro Tip: Bookmark your environment URL for quick access:
https://[your-env-id].live.dynatrace.com

9 Explore OneAgent Installation
  • Click on "Start installation" under OneAgent
  • Select your operating system:
    • Linux
    • Windows
    • AIX
    • z/OS
  • Note the installation command displayed (don't run it yet)
  • Observe that it includes your environment ID and token automatically

Example OneAgent Installation Command (Linux):

wget -O Dynatrace-OneAgent-Linux.sh "https://[env-id].live.dynatrace.com/api/v1/deployment/installer/agent/unix/default/latest?arch=x86&flavor=default" sudo /bin/sh Dynatrace-OneAgent-Linux.sh

Step 5: Managing Access Tokens

What are Access Tokens?

Access tokens are authentication credentials used by OneAgent, APIs, and integrations to securely communicate with your Dynatrace environment.

10 View Existing Tokens
  • Click on your profile icon (top right corner)
  • Select "Access tokens" from the dropdown menu
  • Or navigate to: Settings → Integration → Access tokens
  • You'll see a default token already created: "Default OneAgent install token"
📸 Screenshot: Access tokens management page
11 Create a New Token
  • Click "Generate new token" button
  • Enter a token name: Lab-API-Token
  • Search and select the following scopes:
    • API v2: Read entities, Read metrics, Write metrics
    • API v1: Access problem and event feed
    • Logs: Ingest logs
  • Click "Generate token"
  • Copy the token immediately (you won't see it again!)
  • Store it securely in a text file for future use
⚠️ Security Best Practice:
  • Never share tokens publicly or commit them to source control
  • Create separate tokens for different purposes
  • Use minimum required scopes (principle of least privilege)
  • Rotate tokens periodically
  • Revoke unused tokens immediately

📝 Common Token Scopes

Scope Purpose
InstallerDownload Download OneAgent installer
DataExport Export monitoring data
ReadConfig Read configuration via API
WriteConfig Modify configuration via API
metrics.read Query metrics via API v2
metrics.write Push custom metrics
logs.ingest
